# Calculadora

Calculadora web que faz as quatro operações básicas e aceita parênteses, feita com HTML, CSS e JavaScript puro.

> Projeto feito acompanhando um curso de JavaScript do Roger Melo(Udemy), como prática. Depois do curso, fiz ajustes por conta própria: título e favicon, display só de leitura e acessibilidade nos botões.

🔗 **Acesse:** https://minha-primeira-calculadora-two.vercel.app/

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- Soma, subtração, multiplicação e divisão, com parênteses
- Botão **C** para limpar tudo e **«** para apagar o último caractere
- Tecla **Enter** para calcular
- Aviso de "Conta inválida" quando a expressão não pode ser calculada

## O que aprendi

- Capturar cliques com `addEventListener` e identificar o botão clicado pelas classes
- Manipular o DOM, lendo e alterando o valor do display
- Organizar o código com uma função construtora e `this`
- Tratar erros com `try/catch`
